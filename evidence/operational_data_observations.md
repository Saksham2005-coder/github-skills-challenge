# Operational data observations

1. Metrics:
   - response_time_ms
   - cpu_percent
   - memory_percent

2. Log fields:
   - log_level
   - message

3. Timestamp:
   - timestamp is used to track when the event occurred

4. Normal behaviour:
   - low latency, low CPU, low memory, INFO-level logs

5. Unusual behaviour:
   - very high response time, high CPU, high memory, ERROR or WARNING messages
